# 段階的な制作計画

|段階|成果物|完了条件|現在|
|---|---|---|---|
|0 基本設計|対象分野、管理・参照契約、記入書式、空カタログ|文書整合・個人情報・構造検査と保存確認|今回の範囲|
|1 制作準備|ライセンス方針、担当者、1件の対象とゲート|責任者・権利・必要レビューの確認|未着手|
|2 最初の共有知|子育て・教育の狭いテーマ1件|出典照合、対象条件、反証、評価ケース、必要レビュー|未制作|
|3 別分野での検証|軽量の防災テーマ1件|同じ契約で過不足なく制作できること|未制作|
|4 初回配布|少数のActive項目、Coreセット、manifest、訂正記録|版固定・取得・撤回・オフラインの受入試験|未実装|
|5 分野拡張|残りの初期分野を1件ずつ追加|分野別の根拠とレビュー体制を確保|未着手|
|6 自動化・分割|検査・検索・配布補助、必要なら分野別リポジトリ|実測した負担削減が開発・保守負担を上回る|必要時に提案|

子育ての具体的なテーマ・対象年齢・地域は次工程で決めます。現在の分野表を、具体的助言の一括制作承認とは扱いません。健康・医療等の高影響領域はレビュー担当を確保できた範囲から進めます。

## 本体へ接続する時の変更範囲

本体READMEとCore Life Skills設計書から共有知の入口へリンクし、個人KBには参照元・版・更新方針だけを登録する最小差分を候補とします。本体の既存導入フローは変更しません。今回、本体リポジトリや個人KBの既存文書は変更しません。

## 成果を測る

アクセス数や投稿数だけでは測りません。必要な情報に到達する手間、重大な見落とし、適用不能な提案、利用者の理解、訂正が反映されるまでの時間を評価候補とします。測定への参加とデータ共有は別々に任意とし、個人データがなくても参照利用を継続できます。
