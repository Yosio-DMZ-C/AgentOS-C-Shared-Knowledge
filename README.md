# AgentOS-C Shared Knowledge

人生の重要な場面で、必要な知識・有力な仮説・適した選択肢へ到達するための、公開共有知の基盤です。

**読んで使うだけでも参加できます。共有知の更新への協力は任意です。** 個人の相談、利用履歴、健康・家族・購入情報を提供する必要はありません。

## 現在地

基本設計 v0.1.0。対象分野、知識の記録契約、レビュー、更新・撤回、AgentOS-Cからの参照方法を定義しています。

**利用可能なActiveプレイブックは0件です。** この段階は仕組みと制作範囲の公開であり、医療・法律・金融等の具体的な助言集、専門家紹介サービス、動作する自動同期システムではありません。各分野の共有知は次工程から作ります。

## 何をしようとしているか

困ったときに一から大量の情報を調べなくても、「今わかっていること」「自分に当てはまる条件」「次の1行動」を確認できる短いプレイブックを育てます。

- 確立した知見だけでなく、有力な仮説も根拠・不確実性・リスクを区別して扱う。
- 人気や投稿数を正しさとせず、出典の質・独立性・反証・適用条件を確認する。
- 第一候補と適合理由を短く示し、必要なら確認済み専門家や専門領域へつなぐ。
- 誤りは訂正し、重大な問題は撤回する。古い版を利用している人にも追跡可能な記録を残す。
- 最終的な選択は本人が行い、結果を保証しない。妥当な判断過程と偶然の成功を区別する。

## 本体との関係

|場所|役割|
|---|---|
|[AgentOS-C本体](https://github.com/Yosio-DMZ-C/AgentOS-C)|導入、個人KBの運用、共通品質ゲート|
|このリポジトリ|共有知の正本、分野別カタログ、根拠・改訂・撤回の管理|
|利用者自身の非公開KB|本人の条件、選択、利用結果、個人向け調整|

Coreは別の知識コピーではなく、共有知から選ぶ小さな標準セットです。個人KBへの参照・取り込みと、共有側への投稿は別操作にします。

## 実装・権利の境界

本リポジトリにあるのは文書とJSONの初期契約です。承認を強制するブランチ保護、CI、検索、通知、同期は未実装・未設定です。公開されていることと、内容の専門検証が完了していることを混同しません。

公開・再利用ライセンスは未決定です。個別出典の権利と、本プロジェクト独自部分のライセンスを分離し、正式な配布・取り込み用リリースの前に決定します。第三者資料の全文を収集・再配布する場にはしません。
